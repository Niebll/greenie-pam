## Tentang Project

**Greenie**: aplikasi Android sosial media untuk merawat tanaman (feed postingan, koleksi tanaman, jadwal siram & pupuk, jurnal pertumbuhan, pustaka tanaman).
Dikerjakan tim mahasiswa. Teks UI dan komentar kode memakai **Bahasa Indonesia**.

- **Bahasa:** Kotlin
- **UI:** Jetpack Compose + Material 3 (tema gelap saja)
- **Navigasi:** Navigation Compose
- **State:** ViewModel + StateFlow
- **DI:** Koin
- **Backend:** Supabase via `supabase-kt` (auth-kt, postgrest-kt, storage-kt) + Ktor engine
- **JSON:** kotlinx.serialization
- **Gambar dari URL:** Coil 3 (`coil3.compose.AsyncImage`)
- **Ikon:** Material Icons (`material-icons-extended`), pakai varian `Icons.Outlined.*`
- **Font:** bawaan sistem (`FontFamily.Default`)
- **minSdk:** 26
- **Package root:** `com.greenie.app`

## Struktur Folder (feature-first)

```
app/src/main/java/com/greenie/app/
├── App.kt                    ← startKoin { modules(...) }
├── MainActivity.kt           ← setContent { GreenieTheme { ... } }
├── navigation/               ← Routes.kt, AppNavHost.kt
├── core/                     ← hanya untuk yang dipakai ≥ 2 fitur
│   ├── designsystem/
│   │   ├── theme/            ← Color, Type, Dimens, Gradient, Theme
│   │   └── component/        ← komponen reusable (prefix Greenie…)
│   ├── supabase/             ← SupabaseClient (singleton Koin)
│   ├── model/
│   └── util/
└── feature/<nama-fitur>/
    ├── data/
    │   ├── model/            ← data class
    │   └── XxxRepository.kt
    ├── ui/<nama-screen>/     ← satu folder per screen
    │   ├── XxxScreen.kt
    │   ├── XxxViewModel.kt
    │   ├── XxxUiState.kt
    │   └── component/        ← komponen khusus screen ini
    └── XxxModule.kt          ← module Koin fitur ini
```

Contoh nyata: `feature/beranda/` (screen `ui/feed/BerandaScreen.kt`).

## Arsitektur

Alur: **Screen → ViewModel → Repository → Supabase**

- **Screen** hanya menampilkan `UiState` dan meneruskan aksi user ke ViewModel. Pisahkan jadi:
    - `XxxScreen(...)`: mengambil ViewModel lewat `koinViewModel()` dan collect state dengan `collectAsStateWithLifecycle()`
    - `private fun XxxContent(state, onAksi...)`: stateless, dipakai juga oleh `@Preview`
- **ViewModel** menyimpan `MutableStateFlow<XxxUiState>` privat dan mengekspos `StateFlow` publik. Update state dengan `_uiState.update { it.copy(...) }`. Proses async pakai `viewModelScope.launch`.
- **Repository** adalah satu-satunya tempat query ke Supabase. Menerima `SupabaseClient` lewat constructor.
- **UiState** berupa `data class` dengan default value, dan wajib punya `isLoading` + `error` kalau screen mengambil data.
- Navigasi ke screen lain dikirim sebagai lambda parameter dari Screen (`onPostClick: (Long) -> Unit`), **bukan** dipanggil dari ViewModel.

### Dilarang
- Query Supabase di ViewModel atau Composable
- Menyimpan `Context`, `Activity`, atau Composable di ViewModel
- Satu fitur meng-import kode dari fitur lain. Kalau perlu dipakai bersama, pindahkan ke `core/`
- Membuat ViewModel tanpa mendaftarkannya di module Koin

## Menambah Fitur / Screen Baru

1. Buat model di `feature/<fitur>/data/model/` (`@Serializable`, pakai `@SerialName` untuk kolom snake_case)
2. Buat `XxxRepository` di `feature/<fitur>/data/`
3. Buat `XxxUiState`, `XxxViewModel`, `XxxScreen` di `feature/<fitur>/ui/<screen>/`
4. Daftarkan di `XxxModule.kt`:
   ```kotlin
   val xxxModule = module {
       single { XxxRepository(get()) }
       viewModel { XxxViewModel(get()) }
   }
   ```
5. Tambahkan `xxxModule` ke `modules(...)` di `App.kt`
6. Tambahkan route di `navigation/`
7. Tambahkan `@Preview` (bungkus dengan `GreenieTheme { }`)

## Design System

Sumber: Figma **Greenie – Plants Social Media**, page **🌿 Design System**
(`https://www.figma.com/design/HiUOe4BLbiOgGb8OjQzhcL/Greenie---Plants-Social-Media?node-id=49-173`).
Screen per fitur ada di **Page 1**, dikelompokkan per section "Fitur N · …".

Nama token di kode sama dengan nama di Figma:

| Figma | Kode |
|---|---|
| `text/primary` | `GreenieTheme.colors.text.primary` |
| `surface/card` | `GreenieTheme.colors.surface.card` |
| `border/default` | `GreenieTheme.colors.border.default` |
| `icon/primary` | `GreenieTheme.colors.icon.primary` |
| `Heading/28` | `GreenieTheme.typography.heading28` |
| `Body/13 Medium Paragraph` | `GreenieTheme.typography.body13MediumParagraph` |
| `space/16` | `GreenieTheme.spacing.space16` |
| `radius/16` | `RoundedCornerShape(GreenieTheme.radius.radius16)` |
| Gradient/Canvas | `Modifier.greenieCanvas()` |
| Gradient/Card hijau, emas | `GreenieGradients.cardGreen`, `GreenieGradients.cardGold` |
| Gradient/Shade foto | `GreenieGradients.photoShade` |

Padding horizontal layar standar: `GreenieTheme.spacing.screenHorizontal` (20dp).

### Aturan
- **Jangan** hardcode `Color(0xFF…)`, `xx.sp`, atau spacing/radius di screen. Selalu pakai token `GreenieTheme`.
  Pengecualian: ukuran komponen dari Figma (mis. `48.dp`, `330.dp`) dan nilai mentah Figma yang tidak punya token. Beri komentar.
- **Jangan** pakai `GreeniePalette` (warna primitif) di luar `theme/`.
- **Jangan** pakai `MaterialTheme.colorScheme` atau `MaterialTheme.typography` langsung. Pakai `GreenieTheme`.
- Efek (shadow, blur) **tidak dipakai**. Navbar kaca cukup pakai warna `surface.navbar`.
- Satu layar maksimal satu tombol aksi utama berwarna emas (`surface.accent`).
- Target sentuh minimal 44dp.
- Komponen harus stateless, menerima `modifier: Modifier = Modifier`, dan punya `@Preview`.
- Kalau mengimplementasi dari Figma, cocokkan dengan screenshot frame-nya, dan pakai komponen yang sudah ada sebelum membuat yang baru.

### Komponen yang sudah ada (`core/designsystem/component/`)

| Komponen | Keterangan |
|---|---|
| `GreenieNavbar(selected, onItemClick, onJournalClick)` | Bottom nav 4 menu (`NavbarItem`) + tombol Jurnal di tengah |
| `GreenieIconButton(icon, contentDescription, onClick, size = 44.dp)` | Tombol ikon bulat gaya kaca |
| `GreenieAvatar(name, size, background, textStyle)` | Avatar bulat berisi inisial nama |

Kalau menambah komponen di `core/designsystem/component/`, tambahkan juga ke tabel ini.

### Navbar
`GreenieNavbar` dipasang **sekali** di MainScreen (melayang di atas konten), **bukan** di dalam tiap screen tab.
Screen tab (Beranda, Pustaka, Jadwal, Koleksi) wajib memberi padding bawah sekitar 120dp di `LazyColumn` supaya item terakhir tidak tertutup navbar.

## Supabase

- URL dan anon key dibaca dari `BuildConfig.SUPABASE_URL` / `BuildConfig.SUPABASE_ANON_KEY` (sumber: `local.properties`).
- **Jangan** commit `local.properties`, **jangan** hardcode key, **jangan** pernah memakai `service_role` key di aplikasi.
- Setiap tabel baru wajib RLS aktif. Jangan mengubah skema tabel tanpa persetujuan user.
